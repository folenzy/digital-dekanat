# «На связи», волна 1 — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Рабочий кабинет «На связи» (студент + сотрудник единого деканата) с ядром ТЗ, обращениями с маршрутизацией и SLA, «Деканат пишет первым», realtime-уведомлениями, ночным сбросом демо и файлами деплоя на VPS.

**Architecture:** Одно приложение Next.js (App Router) на TypeScript. Весь доступ к данным идёт через серверный слой `src/server/*`: он получает `Viewer` из сессии и сам фильтрует данные по владельцу. Мутации выполняются через Server Actions, realtime — через SSE (`/api/events`) поверх PostgreSQL `LISTEN/NOTIFY`. Вся бизнес-логика принимает `now: Date` параметром, а часовой пояс фиксирован: Europe/Moscow.

**Tech Stack (версии сверены через `npm view` 2026-11-07):** next 16.4.5, react/react-dom 19.3.1, typescript 5.9.3 (ставит create-next-app; TS 7 не берём), drizzle-orm 0.45.4 + drizzle-kit 0.31.11, postgres (porsager) 4.1.0, @node-rs/argon2 2.2.2, zod 4.6.7, vitest 5.1.0, @playwright/test 1.65.0, @axe-core/playwright 4.14.0, lucide-react 1.70.0 (ISC), @fontsource-variable/literata 5.3.0 (OFL-1.1), @fontsource-variable/golos-text 5.3.0 (OFL-1.1), tsx 4.23.15. Стили: CSS Modules + CSS-переменные (без Tailwind). PostgreSQL 17 в Docker.

**Spec:** `docs/specs/2026-11-07-na-svyazi-design.md`

## Global Constraints

- Только вымышленные данные; вуз «Университет Ориентир», кабинет «На связи», подзаголовок «цифровой деканат».
- Пометка «Концепт для конкурса · не официальный сервис» видна на каждом экране и на странице входа.
- Мобильная ширина от 360 px без горизонтального скролла; десктоп от 1024 px.
- Часовой пояс бизнес-логики Europe/Moscow; любая функция, зависящая от времени, принимает `now: Date`.
- Пароли только argon2id; в БД хранится только хеш токена сессии (sha-256).
- Каждая функция чтения или записи данных студента берёт `studentId` из `Viewer`, а не из аргументов от клиента. Чужое обращение или запись → `null` → 404.
- Секреты только в env: `.env*` не читать, не выводить, не коммитить; `.env.example` в git.
- Шрифты self-host через @fontsource, только с кириллицей; всё стороннее перечислено в `LICENSES.md`.
- Тексты интерфейса на русском; к пользователю на «ты».
- Next.js 16: перед использованием API (proxy/middleware, server actions, cookies, instrumentation) сверяться с документацией в `node_modules/next/dist/docs/`, если она есть, иначе с nextjs.org/docs. По памяти не писать.
- Журнал: после каждой задачи добавить запись в `docs/process/LOG.md` (что сделано, скилл/субагент, ошибки ИИ, ручные шаги).
- Коммиты небольшие, с подписью `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Не пушить.

## Review Focus

1. **Полночь по Москве при сервере в UTC:** в 23:30 UTC в Москве уже следующий день, и «сегодня» должно быть днём по МСК. Тест в Task 5.
2. **Выходной или пар нет:** экран «Сегодня» показывает «Сегодня пар нет» и ближайшую пару в будущем, а не пустоту. Тест в Task 5.
3. **Двойной тап «Отправить» на телефоне:** одинаковое обращение от того же студента в течение 10 с не создаётся дважды, возвращается существующее. Тест в Task 6.
4. **HTML, эмодзи и длинный текст в обращениях и сообщениях:** хранится как текст, выводится экранированным, не ломает 360 px. Тест в Task 6 (сервер) и Task 15 (e2e).
5. **Ночной сброс при открытой вкладке:** старая cookie больше не действует, пользователь попадает на `/login?reason=expired` с пояснением «Сессия завершилась — возможно, ночью обновились демо-данные. Войди снова», SSE закрывается. Тест в Task 3 и Task 15.
