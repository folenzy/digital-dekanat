### Task 13: Экраны «Деканат» — Спроси деканат, новое обращение, карточка обращения

**Скилл:** `frontend-design`.

**Files:** `src/app/(student)/dekanat/**`, `src/app/(student)/dekanat/actions.ts`

**Interfaces:** Task 6, 8, 9.
- «Спроси деканат»: поле → до 3 ответов, у каждого кнопка «Оформить» (на нужный тип) и «Не помогло — написать сотруднику» → `/dekanat/new?topic=…&text=…`.
- Мастер: шаг 1 тема, шаг 2 подтип (`title`, `hint`, срок «обычно отвечаем за N раб. дн.»), шаг 3 форма; перед отправкой — «Уйдёт в: <отдел> · ответ до <дата>». Кнопка блокируется на время отправки. Параметры `?type=&prefill=1` открывают шаг 3.
- Карточка: таймлайн, срок с обратным отсчётом (просрочено — красным), переписка, поле ответа (скрыто для `rejected|closed`), «Получил» для `ready`.
- Чужой или несуществующий id → страница 404 «Обращение не найдено».
