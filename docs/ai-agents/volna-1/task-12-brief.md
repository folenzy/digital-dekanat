### Task 12: Экраны студента — вход, Сегодня, Пары, Учёба, Профиль, Уведомления, О проекте

**Скилл:** `frontend-design`.

**Files:** страницы из «Структуры файлов» для `(auth)`, `(student)` (кроме `dekanat`), `about`; `loading.tsx` и `error.tsx` для каждого сегмента.

**Interfaces:** используют функции Task 4, 5, 7, 9. Каждая страница вызывает `requireStudent()`.
- Вход: поля, кнопка с состоянием загрузки, ошибка «Неверный логин или пароль», «Слишком много попыток, попробуй через N мин», `?reason=expired` → «Сессия завершилась — возможно, ночью обновились демо-данные. Войди снова» (cookie есть, а сессии нет — `getViewer` редиректит сюда).
- Уведомления: вкладки «Уведомления · Объявления»; «Прочитать всё»; пустые состояния «Новых уведомлений нет».
- Сегодня: блоки по спеке §7.2 в этом порядке; пустые состояния: «Сегодня пар нет. Следующая — <день>, <пара>», «Активных обращений нет. Написать в деканат →».
- Пары: «День / Неделя», полоса дней, стрелки недель, чётность, бейджи изменений, подсветка текущей пары.
- Учёба: сводка-вердикт, вкладки «Семестр · Сессия · Зачётка».
- Профиль: поля по §7.7, «Выйти», ссылка «О проекте».
- О проекте: концепт для конкурса, вымышленные данные, ночной сброс в 04:00 МСК, как устроена защита простыми словами.
