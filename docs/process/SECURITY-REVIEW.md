## Почему не применимо / принятые решения

- **Пароли демо-аккаунтов опубликованы в README.** Так требует ТЗ (жюри входит тестовыми учётками). Это вымышленные люди, смены пароля в демо нет, всё откатывается ночным сбросом.
- **Общий аккаунт сотрудника.** Любой эксперт может опубликовать объявление всем студентам. Ограничено 10 объявлениями в час, длиной текста, экранированием вывода и ночным сбросом.
- **Предзагрузка с заголовком `next-router-prefetch` проходит мимо proxy (без CSP и без редиректа).** Права всё равно проверяет `requireStudent`/`requireStaff`. Чужой сайт не может заставить браузер жертвы отправить такой заголовок при навигации, поэтому получить страницу без CSP в браузере жертвы нельзя.
- **HSTS без `includeSubDomains`/`preload`.** Адрес — поддомен `sslip.io`, который нам не принадлежит, поэтому preload неуместен.

## Известные ограничения (осознанно оставлены в волне 1)

Ни одно не даёт доступа к чужим данным; большинство — устойчивость общего демо.

1. **Сессии:** при повторном входе старая сессия не удаляется; число живых сессий на пользователя не ограничено (рост таблицы при множестве успешных входов). Смягчение: вход требует пароля, истёкшие сессии чистятся при входе, ночной сброс удаляет все сессии.
2. **IPv6:** лимит по IP считается по полному адресу (/128), а не по /64; владелец подсети может менять адреса. Пароли демо и так публичны; argon2 делает перебор дорогим.
3. **Фиктивный хеш** для неизвестного логина создаётся при первом запросе: только первый запрос после старта отличается по времени.
4. **Всплеск по одной паре «логин + IP»** временно увеличивает счётчик IP (ошибка в безопасную сторону).
5. **Двойное нажатие «Отправить» ровно на границе лимита** создаёт одно обращение, а второй ответ может быть «слишком часто» (кнопка в интерфейсе блокируется после нажатия).
6. **Поток событий SSE:** нет ограничения числа одновременных потоков на пользователя и backpressure. Потоки не держат соединений с БД (один общий `LISTEN`).
7. **Отметка уведомления прочитанным при открытии карточки (GET).** Чужой сайт ссылкой может отметить уведомление прочитанным (SameSite=Lax пропускает навигацию). Только отметка, без утечки.
8. **Страница 404 внутри кабинета отдаёт HTTP 200** (из-за потоковой загрузки `loading.tsx`); содержимое — обычная 404, существование чужих объектов не раскрывается.
9. **`/_global-error` пререндерится без nonce** (страница крайнего сбоя без пользовательских данных).
10. Мелочи: нет тестов гонок «сообщение студента vs «Готово»» и «отклонить vs взять в работу» (переходы защищены `SELECT … FOR UPDATE`); ветка проверки origin в `isSafeHref` не покрыта тестом под Node; клиент при недоступности сервера повторяет пробу каждые 3 с без роста паузы; переменная `APP_ORIGIN` в compose обязательна, но кодом не читается.
11. **Не проверено локально (делает пользователь при деплое):** выпуск сертификата Let's Encrypt для `<IP>.sslip.io` и доступность сайта из России без VPN.
