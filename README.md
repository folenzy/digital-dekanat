## Идея: деканат, до которого можно достучаться

Автору чаще всего мешало одно: непонятно, куда писать, чтобы вопрос дошёл до деканата, списаться трудно, ответы идут долго. Кабинет отвечает на это четырьмя вещами:

1. **Куда писать — всегда понятно.** Одна кнопка «Новое обращение»: тема → подтип → короткая форма. Перед отправкой видно: «Уйдёт в: Учебный отдел · ответ до <дата>» (срок считается в рабочих днях по Москве). Обращение само попадает в нужный отдел.
2. **Кто и когда — видно, как у посылки.** Таймлайн статусов (Отправлено → В работе (кем) → Нужно уточнение → Готово / Отклонено), обещанный срок с обратным отсчётом, переписка внутри обращения.
3. **«Деканат пишет первым».** На экране «Сегодня» до трёх персональных карточек по правилам: «ты проходишь на повышенную стипендию — подать в 1 тап», «для допуска не хватает контрольной точки», «пересдача по долгу», «справка готова — забери в каб. 214», «деканат ждёт уточнение», «пару перенесли».
4. **Ответ приходит сразу.** Уведомления в реальном времени (SSE + PostgreSQL `LISTEN/NOTIFY`): тост, счётчик на колокольчике и обновлённая карточка без перезагрузки.

Ещё:
- **«Спроси деканат»** — поиск по базе ответов вымышленного вуза (полнотекстовый поиск PostgreSQL по-русски) со ссылкой «Оформить» на нужный тип обращения и кнопкой «Не помогло — написать сотруднику».
- **Кабинет сотрудника** — очередь «Новые / В работе / Ждут студента / Закрытые» с таймерами до конца срока, просроченные подсвечены красным; взять в работу, ответить, запросить уточнение, «Готово» (для справки — где забрать), отклонить с причиной; публикация объявлений для всех / факультета / курса / группы.
- **Ядро по ТЗ:** вход и профиль; расписание на день и неделю с переносами и заменами; успеваемость с вердиктом «как у меня дела», баллами, контрольными точками, сессией и зачёткой; заявки и справки; уведомления и объявления.
- Телефон от 360 px, десктоп от 1024 px; пустые состояния, скелетоны загрузки и ошибки с «Повторить» на каждом экране; проверка доступности axe.

## Безопасность коротко

Пароли — argon2id; в базе только хеш токена сессии; cookie `__Host-`, httpOnly, Secure, SameSite=Lax. Ограничение попыток входа по паре «логин + IP» и по IP, одинаковый ответ на неверный логин и пароль. Каждый запрос к данным берёт студента из сессии, а не из URL; чужое обращение — 404, как несуществующее (IDOR-тесты в Vitest и Playwright). Строгая CSP с nonce, HSTS и другие заголовки. Подробно — `docs/process/DESCRIPTION.md` §5 и `docs/process/SECURITY-REVIEW.md`.

## Стек

TypeScript, Next.js 16 (App Router), PostgreSQL 17 + Drizzle ORM, Docker Compose, Caddy (HTTPS). Тесты: Vitest на реальной PostgreSQL, Playwright (360 px и 1280 px) + axe. Почему так — `docs/adr/0001-stack.md`.

## Запуск локально

Нужны Node 24, npm и Docker Desktop (запущенный).

```bash
npm ci
cp .env.example .env          # в .env впиши пароли демо-аккаунтов (например, из таблицы выше) и DEMO_RESET_TOKEN
npm run db:up                 # PostgreSQL: dev :5432 и test :5433
npm run db:migrate            # миграции
npm run demo:reset            # собрать демо-мир «относительно сегодня»
npm run dev                   # http://localhost:3000
```

Продакшен-сборка локально: `npm run build && npm start` (сервер слушает http://127.0.0.1:3100, а `npm run dev` — :3000). При старте приложение само применяет миграции и, если база пустая, собирает демо-мир.

## Тесты

```bash
npm test                      # Vitest: серверный слой, IDOR, лимиты, правила (нужна test-БД из npm run db:up)
npx playwright test           # e2e на продакшен-сборке, 360 и 1280 px (сам собирает и стартует на :3100)
SCREENSHOTS=1 npx playwright test   # то же + скриншоты в docs/screenshots/ (PowerShell: $env:SCREENSHOTS=1; npx playwright test)
npx tsc --noEmit && npm run lint
```

Последние результаты прогонов — в `docs/process/DESCRIPTION.md`, раздел «Цифры».

## Деплой

Российский VPS (1 vCPU, 1 ГБ RAM), Docker Compose: `app` + `db` + `caddy` + `cron` (ночной сброс демо, ежедневный бэкап). Образ собирается локально и переносится на сервер. Пошагово для новичка — [`docs/DEPLOY.md`](docs/DEPLOY.md).
